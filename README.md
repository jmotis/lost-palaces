# Lost Palaces Project

Interactive 3D models of England's vanished royal palaces, 1428–1703, and the website that presents them.

- `Hugo-site/`: the website, built with [Hugo](https://gohugo.io/). See [Hugo-site/README.md](Hugo-site/README.md) for how it is organised and how to build it.
- `Other Royal Palaces/<palace>/` and `ReconstructingWhitehall Fablecopy/whitehall/`: the 3D models. The website reads each model's page file from here.

The models' images are not in this repository yet; they are being checked for copyright one by one. A copy built from this repository shows the models without those images.
